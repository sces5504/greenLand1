# Repository 實驗指南

## 範圍

本指南僅適用於 `sces5504/greenLand1`。專案已停止開發，允許以小規模、可追蹤的方式驗證 GitHub 工作流程。

## 執行流程

1. 確認目前帳號、目標 Repository、寫入權限及 API 配額。
2. 從最新預設分支建立獨立分支，提出有實際用途的變更。
3. 開啟 PR，檢查檔案差異、機密資料及適用的自動檢查。
4. 確認安全後合併；若有保護規則，依規則完成必要審查。
5. 確認合併結果後，刪除該次建立且已不需要的分支，保留 PR 與 Commit 記錄。

## 限制

- 第一批最多 3 個 PR，先驗證結果再規劃後續工作。
- 不刪除 Repository，不重設歷史，不強制推送，不移除原始重要檔案。
- 憑證使用既有登入或安全 Secrets 機制，不寫入文件、提交或日誌。
- 不偽造共同作者，不製造垃圾 PR 或虛假 Discussions。
- 外部 CLI 執行前先審查來源與依賴；避免自動加星或修改其他 Repository。

## 驗證紀錄

分別記錄已執行的操作、已知條件是否滿足，以及 GitHub 個人頁面實際顯示的成就。CLI 回報成功不代表 GitHub 已頒發成就；可能存在同步延遲或未公開的判定條件。
